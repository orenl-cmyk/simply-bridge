SIMPLY BRIDGE 0.16.4 - Windows x64
=================================

Installer:
  Run SimplyBridge-Setup-v0.16.4-win-x64.exe and then open SIMPLY BRIDGE
  from the Start menu. Administrator rights are not required.

Portable ZIP:
  Extract the entire ZIP into one directory. Do not run the EXE from inside
  the ZIP. Double-click SimplyBridge.exe.

The app opens the default browser on a local address (127.0.0.1) and places
an icon in the Windows notification area. Use that icon to reopen or stop it.

Persistent data and logs:
  %LOCALAPPDATA%\SimplyBridge

The app contains its own Node.js runtime. Docker, Podman, WSL and a separate
Node.js installation are not required. The computer must be able to reach the
configured SIMPLY server addresses over the network.

This build is unsigned. Windows or organizational policy may display a warning
or block it until it is approved or signed with the organization's certificate.
