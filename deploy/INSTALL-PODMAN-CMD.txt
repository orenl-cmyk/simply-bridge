SIMPLY BRIDGE 0.24.1 — עדכון Image באמצעות Podman Compose ו־CMD
===============================================================

תכולת החבילה:
- simply-bridge-0.24.1-linux-amd64.tar — Image עם התגים 0.24.1 ו־current
- קובץ SHA256 ל־TAR ול־ZIP
- compose.yaml — תצורת Compose
- הוראות אלה

עדכון התקנה קיימת
------------------
1. חלץ את ה־ZIP לתיקייה והפעל CMD בה.
2. אמת את קובץ ה־TAR מול simply-bridge-0.24.1-linux-amd64.tar.sha256:

   certutil -hashfile simply-bridge-0.24.1-linux-amd64.tar SHA256

3. הפעל את Podman, ואז טען את ה־Image:

   podman machine start
   podman load -i simply-bridge-0.24.1-linux-amd64.tar

4. באותו חלון CMD, הגדר את BRIDGE_IMAGE לתג החדש ואת שאר הערכים לפי
   הגדרות ההתקנה הקיימת. שמור על PUBLIC_URL, HOST_PORT, BIND_IP ו־DATA_VOLUME:

   set "BRIDGE_IMAGE=simply-bridge:0.24.1"
   set "PUBLIC_URL=http://כתובת-השרת:4318/"
   set "HOST_PORT=4318"
   set "BIND_IP=0.0.0.0"
   set "DATA_VOLUME=simply-bridge-data"

   החלף כתובת וערכים בדוגמאות בערכים הקיימים אצלך. אין להריץ down עם ‎-v.

5. בדוק את ההגדרה והפעל את Image החדש ללא Build או Pull:

   podman compose -f compose.yaml config
   podman compose -f compose.yaml up -d --no-build
   podman compose -f compose.yaml ps
   podman compose -f compose.yaml logs --tail 100 bridge

הנתונים נשמרים ב־Volume שהוגדר ב־DATA_VOLUME. אין להחליף אותו בעדכון.
Image זה מיועד ל־linux/amd64 ומשתמש בתצורה חיצונית, כך שאפשר להגדירו לרשת RED
או BLACK בלי לשנות את הקוד.
